# Roadmap

Possíveis evoluções:

- exportação de históricos em CSV/XLSX;
- filtros avançados nos históricos;
- lote de REA com formato estruturado;
- notificações administrativas ao término de lotes;
- testes automatizados adicionais para regras de negócio;
- compatibilidade validada com novas versões do Moodle.
