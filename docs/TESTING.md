# Testes recomendados

## Dependências

- criação manual;
- múltiplos professores;
- coordenação;
- múltiplos alunos;
- lote com 2 registros;
- lote maior controlado;
- duplicidade;
- erro de usuário inexistente;
- categoria/template inválido.

## REA

- uma disciplina;
- múltiplas disciplinas;
- professor repetido em disciplinas diferentes;
- coordenação opcional;
- preenchimento da área de informações;
- nomenclatura da sala;
- ordenação Material/Entrega;
- seção do aluno.

## Infraestrutura

Durante o processamento, confirme que o Moodle continua navegável e que backup/restore está sendo executado pelo worker CLI, não pela requisição web.
