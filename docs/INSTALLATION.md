# Instalação

1. Copie a pasta `salasatipicas` para `admin/tool/`.
2. Acesse a administração do Moodle.
3. Conclua a atualização de plugins.
4. Limpe os caches.
5. Abra **Administração do site → Cursos → Gerenciar salas atípicas**.
6. Configure templates, categorias e papéis antes da primeira criação.

## Requisitos do servidor

- Moodle 5.0+;
- PHP CLI;
- permissão para iniciar processo PHP em segundo plano;
- método de inscrição manual habilitado.

## Primeira validação

Em homologação, execute inicialmente:

1. uma Dependência manual;
2. um lote de duas Dependências;
3. um REA com uma disciplina;
4. um REA com múltiplas disciplinas.
