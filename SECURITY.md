# Segurança

Não publique vulnerabilidades em issues públicas.

Ao relatar um problema de segurança, inclua:

- versão do Moodle;
- versão do plugin;
- descrição do impacto;
- passos mínimos para reprodução;
- logs relevantes sem dados pessoais.

## Premissas operacionais

O plugin executa operações administrativas de alto impacto, incluindo criação de cursos, restore de templates e matrículas. Por isso, o acesso deve permanecer restrito a usuários administrativos autorizados.
